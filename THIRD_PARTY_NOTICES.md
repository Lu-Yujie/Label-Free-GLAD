# Third-party code and data

Our own code is under the MIT licence in `LICENSE`. This file lists the code and data by others that the
repository includes, fetches or expects you to download.

## Included code (MIT licence)

Each copy is byte-identical to the upstream commit we evaluated, apart from upstream files that are data, figures or
papers, which we left out. The upstream `LICENSE` file sits next to the code. We never edit these copies. Every change
we made lives in our adapter or harness code next to them and is marked `# CHANGE`.

## Code fetched at a pinned commit (no licence)

These repositories have no licence file, so this repository contains none of their code. `scripts/fetch_third_party.sh`
(or `evalpaper/ext/<M>/fetch_src.sh` for one method) clones each repository into `evalpaper/ext/<M>/src/`, checks out
the commit we evaluated and verifies that the working tree is clean. Some of our adapter files reuse lines of this
code. They are shipped as recipes (`evalpaper/ext/<M>/rebuild/*.recipe`) that contain only our own lines and line
references into the fetched files. The fetch script rebuilds them with `scripts/rebuild_from_upstream.py`, which fails
unless every rebuilt file has the sha256 recorded in its recipe.

## Models

GLASS embeds text with the Qwen3-Embedding-0.6B model, which its code downloads from Hugging Face. We do not
redistribute model weights.

## Data

We redistribute only what we derived: fold and held-out index lists, the flipped-orientation folds, the typed-anomaly
suite (graphs generated by our code, and MS-v2 / MolSwap graphs that are edited NCI1 molecules) and our results. The
source graphs are not included. `data/download_tu.sh` downloads them from the TUDataset collection
(https://chrsmrrs.github.io/datasets/; Morris et al., 2020), which also hosts the Tox21 files that UB-GOLD reads, and
checks each archive against the sha256 of the copy we used. Please cite the original datasets and follow their terms.
